# Визуализация — домашнее задание 4

[Открыть дашборд](https://mzaburskaya.github.io/cu_homeworks/visualization/hw_4/)

Автор: Мария Забурская. Датасет: вариант A «Дом и дача».

`index.html` — самостоятельный HTML-файл с Vue.js, D3.js и данными; внешние библиотеки не загружаются. `source.zip` — модульные исходники и скрипт подготовки данных.

Метрики: уникальные заказы, сумма трат и средняя скидка в рублях на единицу. История — 24 месяца, последний месяц — август 2026. Есть фильтр категории, сравнение товаров в штуках и рублях, подсказка с динамикой цены. Только доставленные заказы. Адреса и исходные номера заказов не публикуются. По решению автора изображения товаров не используются.
